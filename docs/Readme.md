# Readme

Zensical based documentation template

  * https://zensical.org

## Commands

| Command                  | Action                                            |
| :----------------------- | :------------------------------------------------ |
| `py build.py build`         | Build the site                                    |
| `py build.py clean`         | clean out the site / build directory              |
| `py build.py serve`         | Serve / preview the site on http://localhost:8000 |

## Virtual Environment

to setup a python virtual environment

```sh
# Make sure tox is installed
pip install tox
# For Windows
./setup_venv.ps1
# For Linux
./setup_venv.sh
```
