# Readme

Example of accessing a Postgresql Database

## Docker Compose Image

Example docker compose file `compose.yml`
```
services:
  db:
    image: "postgres:18"
    container_name: postgres1
    restart: unless-stopped
    environment:
      POSTGRES_USER: "pgadmin"
      POSTGRES_PASSWORD: "%DemoPassword1234"
      # The PostgreSQL default database (automatically created at first launch)
      POSTGRES_DB: default_database
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql
    # set shared memory limit when using docker compose
    shm_size: 128mb

volumes:
  pgdata:
```

## Bringing the docker container up

To bring the container up / down
```sh
# To bring the docker contaner up and run it in daemon mode
docker compose up -d
# To bring the docker container down / delete any stored volumes
docker compose down -v
```

## Create Test Table

Note it's best to use lower case for postgres table names
otherwise you have to use something like public."TestTable1" for the table name

For column names also unless you want to surround the names with double quotes

```sql
CREATE TABLE test_table1 (
    idx INTEGER GENERATED BY DEFAULT AS IDENTITY (START WITH 1 INCREMENT BY 1) NOT NULL,
    test_integer INTEGER NOT NULL,
    test_string VARCHAR(1024) NOT NULL,
    test_datetime TIMESTAMP NOT NULL,
    PRIMARY KEY (idx)
);
```

Insert some values
```sql
INSERT INTO test_table1 (test_integer, test_string, test_datetime) VALUES (2, 'Hello World', '2026-09-13T15:30:00');
INSERT INTO test_table1 (test_integer, test_string, test_datetime) VALUES (3, 'Hello World2', '2026-10-13T15:30:00');
```
